这几个问题现在不能再用 WildCard 早期的虚拟卡教程回答。原来的卡片模式已经停止，新平台使用的是 **WildAI，也就是 bewild.ai**。它的业务重点从“提供虚拟信用卡”转向“帮助用户订阅海外 AI 服务”。官方页面目前展示的产品包括 ChatGPT、Claude、Gemini 和 X 等服务。

## 野卡现在是什么服务？

现在的野卡，更准确地说是 **WildAI AI 订阅平台**。

它的基本流程是：用户先在平台选择需要的 AI 产品和套餐，再按照页面提示登录自己的账号、提交必要的 Session 或 Cookie 信息，平台完成订阅或升级，付款则通过页面提供的支付方式进行。

这和以前的虚拟卡模式有明显区别：

| 对比项目 | 以前的 WildCard | 现在的 WildAI |
| --- | --- | --- |
| 核心服务 | 提供虚拟信用卡 | 帮助订阅海外 AI 服务 |
| 用户是否自己付款给上游 | 通常需要 | 多数流程由平台协助完成 |
| 是否需要申请虚拟卡 | 需要 | 不需要 |
| 主要使用方式 | 自己绑定卡片订阅 | 选择产品后提交账号验证信息 |
| 当前状态 | 已停止新卡服务 | 继续提供 AI 订阅相关服务 |
| 适合人群 | 想自己管理海外付款的人 | 没有海外支付方式、希望直接订阅的人 |

这个转变也解释了为什么网上仍然能看到大量“野卡开卡教程”。其中不少文章讨论的是过去的虚拟卡业务，不能直接代表当前状态。

目前 WildAI 官方首页的定位是帮助用户订阅 ChatGPT、Claude、Gemini 和 X，并支持国内用户常用的付款方式。官方页面还显示，订阅完成通常需要先提交账号凭证或相关订阅链接。

## 野卡目前支持哪些 AI 订阅？

根据官方帮助中心当前公开的订阅教程，WildAI 的产品范围已经不只是一两个 ChatGPT 套餐。

### ChatGPT

官方教程中列出了以下 ChatGPT 订阅档位：

- ChatGPT Plus；
- ChatGPT Pro 5x；
- ChatGPT Pro 20x。

ChatGPT Plus 和 Pro 20x 使用的是登录自己的 ChatGPT 账号、提交账号信息、确认邮箱并付款的流程。官方教程显示，正常情况下付款后大约需要几分钟等待开通，具体时间会受订单和系统状态影响。

ChatGPT Pro 5x 的流程会额外涉及 Cookie 或 Session 信息提交，页面会引导用户在同一浏览器中登录 ChatGPT，再复制所需账号信息。

这里要特别注意：**ChatGPT Plus 会员不等于 OpenAI API 额度**。官方帮助中心明确表示，WildAI 当前提供的是 GPT 会员订阅，不提供 GPT 官方 API 额度充值；Codex 相关额度是否可用，要以订阅页面当时是否出现对应入口为准。

### Claude

官方教程中列出的 Claude 产品包括：

- Claude Pro；
- Claude Max 5 倍；
- Claude Max 20 倍。

Claude 的提交方式与 ChatGPT 不完全相同。官方教程要求使用 Cookie-Editor 等工具导出 Claude 账号 Cookie，再将信息提交到订阅流程中。对于长期套餐，平台可能会按照多月订阅方式预存额度，并按月处理后续订阅。

Claude 对网络环境比较敏感。官方帮助中心多次提醒，订阅和后续使用时不要频繁切换网络节点或 IP，否则可能触发上游平台的风控。这个限制来自 Claude 和相关账号环境，不是单纯换一个付款渠道就能解决的问题。

### Gemini

官方帮助中心当前列出的 Gemini 产品包括：

- Gemini Plus；
- Gemini Pro；
- Gemini Ultra 5x；
- Gemini Ultra 20x。

Gemini 的订阅流程通常需要在电脑端登录 Google 账号，并使用 Cookie-Editor 导出 Google 相关 Cookie。官方教程显示，手机端无法完整完成 Cookie 获取步骤。

Gemini 还有一个容易被忽略的条件：Google 账号所在地区和当前网络环境可能影响订阅与使用。如果账号地区不支持对应服务，即使平台订单已经完成，Gemini 页面也可能仍然显示 Free，或者提示当前地区不支持。官方帮助中心建议先确认账号状态、地区和网络，再判断是订单问题还是上游地区限制。

### X Premium+

WildAI 还提供 X Premium+ 订阅流程。

与 ChatGPT、Claude、Gemini 不同，X 通常不要求安装 Cookie 插件。官方教程要求用户登录 X 账号，打开订阅页面，复制完整的 Stripe 付款链接，再提交到 WildAI 页面进行验证。

需要注意，X Premium+ 与 Grok 不是完全相同的产品。官方帮助中心说明，Grok 与 X Premium 订阅是相互独立的产品，购买其中一个不代表自动包含另一个。

### Claude API

除了 Claude Pro 和 Max，平台帮助中心还公开了 Claude API 充值流程，充值额度包括 **20 美元和 100 美元**两个选项。Claude API 充值使用的是 Claude 账户余额，按 API 使用量计费，不等于 Claude Pro 会员。

这两个产品不要混淆：

- Claude Pro / Max：面向网页端聊天和会员权益；
- Claude API：面向开发者调用模型，按照用量消耗账户余额。

如果你只是想在 Claude 网页端聊天，应该看 Pro 或 Max，而不是 API 充值。

## 单月订阅和长期订阅有什么区别？

官方教程通常把订阅周期分为两种：

- **单次订阅**：购买一个月，到期后结束，不继续续费；
- **长期订阅**：预先选择多个月，价格通常更低，但后续会按照平台规则处理续订。

长期订阅并不等于“买完以后完全不用管”。部分产品会将后续月份预存在平台账户额度中，再按月处理。如果用户在上游官网自行取消订阅，可能影响后续已经预付的月份。官方帮助中心特别提醒，ChatGPT 和 Claude 的长期订阅不要在官方页面随意点击取消，否则可能导致预存月份无法继续使用。

如果你只是想测试某个工具，单月通常更容易控制风险。已经确认需要连续使用，再考虑长期方案。多买几个月确实可能降低平均月价，但也会让退款和升级处理变得更复杂。

## 使用野卡订阅 AI 服务需要提交什么？

不同产品要求不一样。

### ChatGPT

ChatGPT 流程可能要求：

1. 登录自己的 ChatGPT 账号；
2. 在同一浏览器中打开指定页面；
3. 复制 Session 或 JSON 信息；
4. 返回 WildAI 页面提交；
5. 确认邮箱、套餐和价格；
6. 完成付款并等待处理。

提交前应确认账号已经登录正确，尤其是多个 ChatGPT 账号同时使用时，不要把 A 账号的登录信息提交给 B 订单。

### Claude

Claude 通常需要通过 Cookie-Editor 导出 Cookie。提交前要确认：

- Cookie 来自正确的 Claude 账号；
- 账号当前没有未处理的扣款或有效冲突订阅；
- 导出的内容完整；
- 不要把 Cookie 发给无关人员；
- 订阅和后续使用尽量保持稳定网络环境。

官方帮助中心把 Session Key 和 Cookie 都视为账号凭证，并建议用户不要外发。

### Gemini

Gemini 主要需要在电脑端使用 Chrome 等浏览器完成操作。流程通常包括：

1. 登录 Google 账号；
2. 确认账号当前没有冲突的有效订阅；
3. 安装 Cookie-Editor；
4. 按页面要求导出 Google 账号 Cookie；
5. 提交到 WildAI；
6. 付款并等待 Google 侧同步。

如果 Google 账号本身不符合地区条件，平台无法保证订阅后一定能正常使用。这里的关键不是付款成功，而是上游账号是否能够使用对应服务。

## 野卡订阅失败怎么办？

不同产品的处理时间不一样。官方教程中给出的常见范围是：

- ChatGPT：通常约 5 至 15 分钟；
- Claude：通常约 5 至 30 分钟；
- Gemini：通常约 5 至 30 分钟；
- X：付款后可在订单页面查看状态。

如果订单仍在处理中，不建议马上重复购买。重复付款可能造成多个订单同时进入处理状态，后续核对会更麻烦。

可以按下面顺序排查：

1. 先查看订单状态，确认是否只是延迟；
2. 检查提交的账号是否正确；
3. 检查 Cookie、Session 或 Stripe 链接是否完整；
4. 确认上游账号没有已有订阅或未处理账单；
5. 确认当前网络和账号地区符合产品要求；
6. 超过官方提示时间后，再联系客服提供订单号和截图。

Gemini 的官方帮助页面还建议，在订单完成但页面仍显示 Free 时，先确认是否查看了正确的 Google 账号，再强制刷新或重新登录。

## 什么时候可以退款？

退款不能简单理解为“付款后随时取消”。

官方帮助中心目前说明，已经完成履约、权益已经生效的订单，如果只是个人原因不想使用、误选产品或误选套餐，原则上不支持退款。订单仍在处理、尚未生效，或者多月套餐存在未生效月份时，可以联系客服核实是否符合退款或取消条件，但这并不代表一定退款。

以下几种情况尤其要提前确认：

- 买错了 ChatGPT、Claude 或 Gemini；
- 选错 Plus、Pro、Max 或 Ultra 档位；
- 多月套餐还没有全部生效；
- 账号地区不支持上游服务；
- 购买的是 API 充值，而不是会员订阅；
- 通过 App Store 产生的订单；
- 使用历史余额兑换套餐。

其中，App Store 渠道的取消和退款需要在 Apple 侧处理，WildAI 无法代替用户直接操作。余额兑换本身也不支持普通退款，兑换后没有生效时应联系客服核对，不要重复兑换。

## 野卡适合什么人？

野卡现在更适合下面几类用户：

- 没有海外银行卡，但需要订阅 ChatGPT、Claude 或 Gemini；
- 不想自己申请和维护虚拟信用卡；
- 已经有目标 AI 服务账号，希望直接在原账号上升级；
- 希望使用微信、支付宝等方式完成支付；
- 只想订阅某一个月，不想处理复杂的海外付款流程。

但如果你能使用目标服务的官方付款方式，并且所在地区、账号和支付渠道都符合要求，直接通过官方渠道订阅通常更容易管理账单、取消和退款。第三方订阅平台解决的是支付和操作门槛，不会改变 OpenAI、Anthropic、Google 或 X 本身的地区规则、账号规则和风控判断。

## 购买前的核对清单

下单前，建议逐项确认：

- 你要买的是会员订阅，还是 API 额度；
- 产品名称是否正确；
- 套餐档位是否正确；
- 订阅时长是单月还是长期；
- 当前页面显示的总价和币种；
- 是否需要提交 Session、Cookie 或 Stripe 链接；
- 账号是否已经有有效订阅；
- Google 账号或 Claude 账号的地区是否满足要求；
- 订单失败时的退款条件；
- 长期套餐是否会按月继续处理；
- 订阅成功后是否需要保持稳定网络环境。

对于首次使用者，先从单月套餐开始通常更容易判断流程是否适合自己。确认账号、网络和产品都能正常使用，再考虑更长期的订阅。
